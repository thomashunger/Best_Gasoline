Al abrir esta página se consulta primero un mirror diario de los datos oficiales (republicado con cabeceras CORS, por eso es fiable desde el navegador) y, si falla, la API del Ministerio directamente vía varias pasarelas. Si ninguna de las dos responde, se muestra el último snapshot guardado en el archivo. Como el precio oficial solo cambia ~1 vez al día, cada actualización registra el precio más barato del momento en el histórico semanal — el segundo archivo que te compartí — solo cuando cambia respecto al último registro, para que la línea de tiempo no se llene de puntos repetidos. Usa almacenamiento compartido si esta página está abierta dentro de Claude, o guardado local en este navegador si se abrió como archivo descargado (en ese caso no se comparte automáticamente con la otra persona).
